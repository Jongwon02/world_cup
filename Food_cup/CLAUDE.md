## 1️⃣ 프로그램 개요

### 1.1 프로젝트 개요
**음식 월드컵**은 사용자가 랜덤하게 제공되는 100개의 음식을 64강 토너먼트 방식으로 진행하면서 자신이 가장 사랑하는 최고의 음식을 선택하는 인터랙티브 웹 서비스입니다. 토너먼트 완료 후 사용자는 자신의 결과를 공유할 수 있으며, 선택한 모든 음식들을 카드 형식으로 저장할 수 있습니다.

### 1.2 프로젝트 목적
- 재미있는 게임 방식으로 사용자의 음식 선호도를 파악
- SNS 공유를 통한 바이럴 마케팅 효과
- 사용자 간 결과 비교 및 공유 경험 제공
- 사용자의 음식 선택 기록 보관

### 1.3 서비스 범위
- 웹 기반 싱글 페이지 애플리케이션 (SPA)
- 반응형 디자인 (모바일, 태블릿, 데스크톱)
- 브라우저 기반 로컬 스토리지 활용
- 소셜 미디어 공유 기능

### 1.4 대상 사용자
- **연령대:** 남녀노소 모두 (초등학생 ~ 고령층)
- **기술 수준:** 기술 초심자도 쉽게 사용 가능
- **사용 환경:** 모바일, 태블릿, 데스크톱

## 2️⃣ 사용자의 사용 시나리오

### 시나리오 1: 음식 월드컵 참여 (메인 플로우)
```
1. 사용자가 웹사이트에 접속
2. "시작하기" 버튼 클릭
3. 홈페이지에서 100개의 랜덤 음식이 선택됨
4. 64강 토너먼트 진행
   - 화면에 두 개의 음식 이미지와 이름 표시
   - 사용자가 더 좋아하는 음식 선택
   - 선택한 음식이 다음 라운드로 진출
   - 32강 → 16강 → 8강 → 4강 → 결승전 진행
5. 최종 우승자(최고의 음식) 결정
6. 결과 페이지 표시 (우승 음식 표시)
```

### 시나리오 2: 결과 저장 및 공유
```
1. 토너먼트 완료 후 결과 페이지에서 "결과 저장" 버튼 클릭
2. 자신이 선택한 모든 음식이 카드 형식으로 보여짐
3. 카드에는 음식 이미지, 이름, 선택된 라운드(4강, 결승 등) 표시
4. "공유하기" 버튼으로 SNS(카카오톡, 인스타그램, 페이스북 등)에 공유
5. 공유 링크를 통해 타인도 같은 결과 확인 가능
```

### 시나리오 3: 저장된 결과 조회
```
1. 사용자가 "내 결과 보기" 메뉴 클릭
2. 과거에 저장한 모든 음식 월드컵 기록 확인
3. 각 기록마다 "우승 음식", "준우승", "4강", "8강" 등으로 분류된 카드 조회
4. 기록 삭제 또는 재공유 가능
```

### 시나리오 4: 친구 결과와 비교
```
1. 공유받은 링크를 통해 친구의 결과 확인
2. 자신의 결과와 친구의 결과 비교
3. "공통된 선호 음식", "다른 선호 음식" 분석
```

## 3️⃣ 핵심 기능의 목록

### Phase 1: 핵심 기능 (필수)

#### 3.1.1 음식 데이터베이스
- **기능:** 100개의 음식 데이터 관리
- **포함 사항:**
  - 음식명 (한글, 영문)
  - 음식 이미지 URL
  - 음식 카테고리 (한식, 중식, 양식, 일식, 카페, 디저트 등)
  - 음식 설명 (선택 사항)
- **특징:** 서비스 시작 시 100개 중 랜덤 선택 (매번 다른 음식 조합)

#### 3.1.2 64강 토너먼트 엔진
- **기능:** 토너먼트 진행 로직 구현
- **포함 사항:**
  - 64강, 32강, 16강, 8강, 4강, 준결승, 결승 자동 진행
  - 사용자 선택 시 다음 라운드 자동 업데이트
  - 토너먼트 진행 상황 시각화 (진행률 바)
  - 라운드별 음식 매칭 (항상 같은 수준의 경쟁자)
- **사용자 경험:**
  - 직관적인 선택 UI (두 개의 음식 카드 중 선택)
  - 선택 즉시 결과 반영
  - 선택 음식에 하이라이트 효과

#### 3.1.3 결과 저장 기능
- **기능:** 토너먼트 결과 저장
- **포함 사항:**
  - 사용자가 선택한 모든 음식 목록 저장
  - 각 음식의 진출 라운드 기록 (우승, 준우승, 4강, 8강 등)
  - 시간 타임스탬프 기록
  - 브라우저 로컬 스토리지에 저장
- **카드 형식:**
  - 음식 이미지
  - 음식명
  - 진출 라운드 배지 (예: "우승", "4강", "8강")
  - 음식 카테고리 표시

#### 3.1.4 결과 공유 기능
- **기능:** 완성된 결과를 SNS 및 링크로 공유
- **포함 사항:**
  - 고유한 결과 페이지 URL 생성
  - SNS 공유 버튼 (카카오톡, 인스타그램, 페이스북, 트위터)
  - 공유 텍스트 자동 생성 (예: "내 최고의 음식은 피자입니다! 당신의 최고 음식은?")
  - 결과 이미지 자동 생성 (썸네일)
- **특징:**
  - QR 코드 생성 및 공유
  - 단축 URL 지원
  - 공유 카운트 표시

#### 3.1.5 모바일 반응형 UI
- **기능:** 모든 기기에서 최적의 경험 제공
- **포함 사항:**
  - 스마트폰 (320px ~ 480px) 최적화
  - 태블릿 (768px ~ 1024px) 최적화
  - 데스크톱 (1025px 이상) 최적화
  - 터치 친화적 인터페이스 (버튼 크기 최소 44x44px)
  - 제스처 지원 (스와이프로 음식 선택 옵션)

#### 3.1.6 사용자 인터페이스 (UI)
- **기능:** 직관적이고 매력적인 비주얼 디자인
- **포함 사항:**
  - 메인 페이지 (시작하기 버튼)
  - 토너먼트 진행 페이지
  - 결과 요약 페이지 (우승 음식 강조)
  - 저장된 음식 카드 페이지
  - 공유 페이지
  - 내 결과 보기 페이지
- **디자인 특징:**
  - 밝고 친근한 색상 팔레트
  - 음식 이미지 중심의 비주얼
  - 진행 상황 바 및 라운드 표시
  - 로딩 애니메이션

## 5️⃣ 기술 스택 제안

### 프론트엔드
- **HTML5** - 마크업 구조

### 외부 라이브러리
- **html2canvas** - 결과 이미지 생성
- **qrcode.js** - QR 코드 생성
- **Axios** - API 호출 (미래 버전)

## 6️⃣ 성공 기준

### 기능적 성공 기준
- ✅ 토너먼트가 오류 없이 완료될 것
- ✅ 모든 선택한 음식이 정확하게 저장될 것
- ✅ 공유 링크를 통해 타인이 결과를 조회할 수 있을 것
- ✅ 모바일에서도 완벽하게 작동할 것

### 사용성 성공 기준
- ✅ 초보자도 3초 내에 시작할 수 있을 것
- ✅ 전체 토너먼트 완료 시간이 5-10분 이내일 것
- ✅ 공유까지 2클릭 이내로 가능할 것
- ✅ 사용자 만족도 4/5 이상일 것

### 성능 성공 기준
- ✅ 페이지 로드 시간 2초 이내
- ✅ 음식 선택 시 응답 시간 100ms 이내
- ✅ 모바일 환경에서도 부드러운 애니메이션

### 파일 구조
```
Food_cup/
├── index.html           # 메인 HTML 파일
├── css/
│   ├── style.css       # 메인 스타일시트
│   └── responsive.css  # 반응형 스타일
├── js/
│   ├── main.js         # 메인 JavaScript
```

### JavaScript 컨벤션
- ES6+ 표준 준수 (const, let, arrow functions)

- 상수는 UPPER_CASE (예: MAX_ROUNDS)
- 변수명은 camelCase
- 주석은 필요할 때만 작성 (자명하지 않은 로직에만)
